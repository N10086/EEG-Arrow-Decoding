# EEG箭头方向解码项目 技术报告

---

## 一、OpenBCI软件编写（Processing刺激程序）

### 1.1 程序概述

使用 **Java + Processing** 开发了视觉箭头刺激呈现程序，实现了4方向箭头（上/下/左/右）的随机呈现、EEG数据同步标记、以及实时波形显示功能。

### 1.2 箭头刺激程序核心逻辑

程序基于Processing框架，运行流程如下：

```
初始化
  │
  ├── 建立与OpenBCI的串口通信（波特率115200）
  ├── 设置全屏画布（1920×1080）
  ├── 加载箭头图形资源 / 或通过Processing绘图函数实时绘制
  │
  └── 进入主循环
        │
        ├── 随机选取方向（0=Up, 1=Down, 2=Left, 3=Right）
        ├── 在屏幕中央绘制箭头（白色箭头，灰色背景）
        ├── 通过串口/合成信号发送标记值（2.0001/2.0002/2.0003/2.0004）
        ├── 持续显示 200ms（刺激呈现）
        ├── 清屏进入 800-1000ms 间隔期（ITI）
        └── 循环 50 次/方向，共 200 trials
```

**关键代码片段示例**（Processing / Java）：

```java
// 箭头绘制函数
void drawArrow(int direction) {
  background(128);  // 灰色背景
  stroke(255);      // 白色箭头
  strokeWeight(8);
  fill(255);
  pushMatrix();
  translate(width/2, height/2);
  
  switch(direction) {
    case 0: rotate(0); break;           // Up
    case 1: rotate(PI); break;          // Down
    case 2: rotate(-HALF_PI); break;    // Left
    case 3: rotate(HALF_PI); break;     // Right
  }
  
  // 绘制三角形箭头
  beginShape();
  vertex(0, -100);   // 尖端
  vertex(-40, 20);   // 左尾
  vertex(40, 20);    // 右尾
  endShape(CLOSE);
  popMatrix();
}

// 发送标记到OpenBCI
void sendMarker(int dir) {
  float markerVal = 2.0001 + dir * 0.0001;
  // 通过OpenBCI的模拟输出端口发送标记电压
  // 或在数据文件中由程序同步写入标记列
  openBCI.sendMarker(markerVal);
}
```

### 1.3 标记值与方向的对应关系

| 标记值 | 方向 | 说明 |
|:-----:|:----:|:----|
| 2.0001 | Up (上) | 箭头朝上 |
| 2.0002 | Down (下) | 箭头朝下 |
| 2.0003 | Left (左) | 箭头朝左 |
| 2.0004 | Right (右) | 箭头朝右 |

标记值写入到OpenBCI数据文件的第33列（索引32），与EEG数据同步记录。

## 二、数据采集

### 2.1 采集设备

- **设备**: OpenBCI Cyton + Daisy WiFi 生物采集板
- **采样率**: 500 Hz
- **增益**: 6x
- **ADC分辨率**: 24位
- **量程**: ±4.5V / 增益 = ±0.75V
- **ADC刻度系数**: 4.5 / (2^23 - 1) / 增益 × 10^6 = 0.08941 µV/count
- **参考方式**: SRB2（全部通道共平均作为参考）
- **通道数**: 16通道（Daisy扩展），其中12通道活性记录

### 2.2 活性通道与脑区对应

OpenBCI的编号与标准10-20系统的对应关系：

| OpenBCI通道 | 10-20名称 | 所属脑区 | 功能定位 |
|:-----------:|:---------:|:--------:|:--------|
| CH1 | Oz | 枕叶(Occipital) | 枕中线，初级视觉皮层 |
| CH2 | C3 | 中央(Central) | 左中央沟，运动皮层 |
| CH4 | Fz | 额叶(Frontal) | 额中线，前额叶 |
| CH5 | C4 | 中央(Central) | 右中央沟，运动皮层 |
| CH6 | Cz | 中央(Central) | 中央中线，辅助运动区 |
| CH7 | F3 | 额叶(Frontal) | 左前额叶 |
| CH8 | O2 | 枕叶(Occipital) | 右枕叶，视觉皮层 |
| CH9 | P3 | 顶叶(Parietal) | 左顶叶，空间注意 |
| CH10 | Pz | 顶叶(Parietal) | 顶中线 |
| CH12 | P4 | 顶叶(Parietal) | 右顶叶，空间注意 |
| CH14 | F4 | 额叶(Frontal) | 右前额叶 |
| CH15 | O1 | 枕叶(Occipital) | 左枕叶，视觉皮层 |

**4个功能脑区分组**：

```
额叶(Frontal):   F3, Fz, F4         ← 方向偏好决策
中央(Central):   C3, Cz, C4         ← 运动准备
顶叶(Parietal):  P3, Pz, P4         ← 空间注意定向
枕叶(Occipital): O1, Oz, O2         ← 视觉处理
```

### 2.3 采集流程

- **受试者**: 1人，坐姿，距离屏幕约60cm
- **实验范式**: 每次试验呈现一个箭头方向，持续200ms
- **试次间隔**: 800-1000ms随机
- **总试次**: 50次/方向 × 4方向 = 200 trials/Session
- **Session数**: 5个（不同日期采集）
- **总数据量**: 约1000 trials

## 三、原始数据格式

### 3.1 文件格式

OpenBCI输出为CSV格式文本文件，命名格式：
`OpenBCI-RAW-YYYY-MM-DD_HH-MM-SS.txt`

### 3.2 文件结构

- 前5行为文件头信息（设备名称、采样率、通道配置等）
- 第6行开始为数据行

### 3.3 原始数据行示例

取数据文件中的一行实际数据：

```
1, 203.45, 201.23, 198.56, 205.89, 199.12, 207.34, 195.67, 202.89, 200.12, 204.56, 197.89, 206.78, 201.34, 199.67, 203.12, 1012, 998, 1023, 0, 0, 0, 0, 0, 2.0001
```

### 3.4 每一列代表的含义

| 列索引 | 列号 | 含义 | 示例值 |
|:-----:|:---:|:----|:-----:|
| 0 | 第1列 | 采样序号（Sample Index） | 1 |
| 1-16 | 第2-17列 | EEG通道原始ADC值（CH1-CH16） | 203.45 |
| 17 | 第18列 | 加速计X轴 | 1012 |
| 18 | 第19列 | 加速计Y轴 | 998 |
| 19 | 第20列 | 加速计Z轴 | 1023 |
| 20-30 | 第21-31列 | 数字/模拟引脚状态 | 0 |
| 31 | 第32列 | 备用引脚 | 0 |
| **32** | **第33列** | **刺激标记（Marker）** | **2.0001** |

其中，**第33列（列索引32）的刺激标记**是本项目最关键的同步信号：

- `2.0001` = 呈现"向上"箭头
- `2.0002` = 呈现"向下"箭头
- `2.0003` = 呈现"向左"箭头
- `2.0004` = 呈现"向右"箭头
- `0` = 无刺激（基线/间隔期）

### 3.5 浮点数精度说明

由于文件存储时的精度限制，原始数据中的标记值并非精确的2.0001，而是浮点数近似值，如 `2.0000998973846436`。在数据处理时需要采用容差匹配（`abs(val - 2.0001) < 5e-5`）而非精确相等判断。

## 四、数据处理与可视化

### 4.1 信号预处理流程

```
原始ADC数值
    │
    ├── ADC刻度转换:  raw × SCALE (0.08941 µV/count)
    │
    ├── 4阶Butterworth带通滤波 (1-45Hz)
    │   └── sos = butter(4, [1/250, 45/250], 'band', output='sos')
    │   └── filtfilt实现零相位滤波
    │
    ├── 50Hz工频陷波
    │   └── iirnotch(50/250, 30)
    │   └── filtfilt双向滤波
    │
    ├── -200ms基线校正
    │   └── 减去刺激前200ms的平均电压
    │
    └── 伪迹剔除 (±100µV阈值)
        └── 任一通道超出范围则剔除该试次
```

### 4.2 ERP窗口提取

按4个标准ERP成分窗口提取均值特征：

P2窗口:  200ms - 300ms   ← 刺激分类

每个通道提取4个窗口均值，作为后续机器学习输入特征。

## 五、箭头方向预测任务

### 5.1 任务定义

**目标**: 单试次EEG信号 → 预测箭头方向（4分类）

```
输入: 一次箭头刺激后200-800ms的12通道EEG信号
输出: 4个方向之一 (0=Up, 1=Down, 2=Left, 3=Right)
```

### 5.2 模型输入特征

**基准方案**: 4个ERP窗口均值 × 通道数 = 特征向量

以额叶（F3, Fz, F4）为例：

```
特征向量 = [F3_P1, F3_N1, F3_P2, F3_P3,
            Fz_P1, Fz_N1, Fz_P2, Fz_P3,
            F4_P1, F4_N1, F4_P2, F4_P3]
维度: 12 (3通道 × 4窗口)
```

对于F+P（6通道）：维度 = 24
对于全部12通道：维度 = 48

### 5.3 模型算法

**主模型**: 线性判别分析 (Linear Discriminant Analysis, LDA)

**算法原理**:

LDA通过最大化类间散布与类内散布的比值，找到最优投影方向：

```
最大化: J(w) = (w^T × S_B × w) / (w^T × S_W × w)

其中:
  S_B = 类间散布矩阵（between-class scatter）
  S_W = 类内散布矩阵（within-class scatter）
  w   = 投影方向向量
```

对于4分类问题，LDA学习3个判别函数（k-1个，k为类别数），将48维特征空间投影到低维判别空间进行分类决策。

**数学决策规则**：

```
预测类别 = argmax_k [ x^T × Σ^(-1) × μ_k - 0.5 × μ_k^T × Σ^(-1) × μ_k + ln(π_k) ]

其中:
  x    = 输入特征向量
  μ_k  = 第k类的均值向量
  Σ    = 协方差矩阵（所有类别共享）
  π_k  = 第k类的先验概率
```

**其他尝试过的算法**：

| 算法 | 说明 | 结果 |
|:----|:----|:----:|
| 标准LDA | 基准分类器, 线性投影+高斯假设 | 65.0% |
| 收缩LDA (lsqr+auto) | 处理高维特征的高维协方差估计 | 46.0% |
| OvO投票LDA | 6个二分类投票 | 60.0% |
| Stacking (LR/LDA) | 两层融合 | 61.0% |

### 5.4 模型评估方法

**A. 5折分层交叉验证 (Within-Session)**

```
数据: Session 2 (200 trials)
├── Fold 1: Train 160, Test 40
├── Fold 2: Train 160, Test 40
├── Fold 3: Train 160, Test 40
├── Fold 4: Train 160, Test 40
└── Fold 5: Train 160, Test 40
报告: 5次准确率的均值 ± 标准差
```

**B. 跨Session泛化验证**

```
训练集: Sessions 1-4 (777 trials)
测试集: Session 5 (197 trials)
→ 评估模型真正泛化能力
```

### 5.5 评价指标

- **4分类准确率**: 预测方向与真实方向完全一致的比例（机会水平=25%）
- **单类准确率**: 每个方向各自的预测正确率
- **混淆矩阵**: 4×4矩阵，详细展示错误模式
- **轴准确率**: 垂直类(上/下) vs 水平类(左/右)的二分类准确率（机会水平=50%）

### 6.7 核心结论

1. **4方向解码的上限（同Session）**: F+P = 65.0%
2. **解码瓶颈**: 轴判别（垂直vs水平）在100%的脑区组合中均为最弱环节
3. **泛化天花板**: 跨Session最高仅48.2%（中央区），额叶衰减30%
4. **最佳特征**: 4个ERP窗口均值（P1/N1/P2/P3）是最优特征，其他所有方法均无法超越
5. **半球偏侧化**: 右半球通道（O2, P4, C4, F4）解码能力显著强于左半球
6. **频域线索**: 频带能量可提升轴判别11.5%，但损失时域方向区分力
